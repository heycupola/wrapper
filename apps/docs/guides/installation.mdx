Wrapper supports macOS and Linux. On Windows, use WSL.

## Install the CLI

### Homebrew

```bash
brew install heycupola/tap/wrapper
```

If Homebrew reports that Xcode is outdated, update Command Line Tools or use the
curl installer below. The formula only unpacks a release binary; it does not
build Wrapper with Xcode. See [Troubleshooting](/troubleshooting).

### Checksum-verified installer

```bash
curl -fsSL https://wrapper.sh/install | bash
```

The installer downloads a release tarball from GitHub Releases, verifies
`checksums.txt`, and installs under `$HOME/.wrapper` (override with
`WRAPPER_INSTALL_DIR`). Optional pins:

```bash
WRAPPER_VERSION=v0.2.0 curl -fsSL https://wrapper.sh/install | bash
```

Confirm:

```bash
wrapper --version
```

## Get iOS viewer beta

The iPhone and iPad app is a TestFlight viewer, not a host. The shell, files,
and credentials stay on the Mac or Linux machine. After the CLI is installed
and a session is shared, attach from iOS.

See [Mobile viewer](/guides/mobile-viewer).

## Share a session

No rc hook is required:

```bash
wrapper auth login
wrapper share
```

Wrap a command without sharing yet:

```bash
wrapper run -- claude
```

Prefer a remote Linux box? See [Remote Linux box](/guides/linux-remote).

## Optional shell hook

`wrapper install` is optional. It patches rc files so every new interactive
shell is wrapped. Sharing does not need this.

```bash
wrapper install --dry-run
wrapper install
```

## Sign in

Remote share needs a Wrapper account. Local attach uses the loopback token
only:

```bash
wrapper auth login
```

Approve the device code at the printed URL. Check status with
`wrapper auth whoami`.

See [Authentication](/guides/auth) for token storage and logout.

## Attach locally

From another terminal on the same machine:

```bash
wrapper status
wrapper attach
```

Local attach uses loopback plus a per-session token from your session registry.
It does **not** use the Fly relay, Convex, or Pro.

See [Local attach](/guides/local-attach).

## Share remotely (Pro)

`wrapper share` shares immediately. In a running host, press `Ctrl+\` then `s`.
Wrapper prints a share code and join command when the shell is idle.

Owner join from any device:

```bash
wrapper attach --relay --id <sessionId>
```

Guest join uses the same command and a hidden share-code prompt. Press
`Ctrl+\` then `u` to revoke access.

<Warning>
  Every accepted viewer can read output and send input. There is no watch-only mode.
</Warning>

See [Remote share](/guides/remote-share), [Pricing](/reference/pricing), and
[Security and privacy](/configuration/security).
