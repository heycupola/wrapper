Wrapper wraps every interactive shell you open so an authenticated device can
mirror it on demand. Your shell stays local until you choose to share it, and
the wrapping is invisible: your dotfiles, prompt, plugins, and history behave
exactly as before.

## The parts

- **CLI** (`apps/cli`): hosts your shell inside a PTY, runs a local WebSocket
  server, and bridges to the relay when you share.
- **Backend** (`packages/backend`, Convex): authentication (Better Auth),
  session lifecycle, relay join tickets, onboarding, and billing (Autumn).
- **Relay** (`apps/relay`, Fly.io): an authenticated WebSocket router that
  connects a host to its viewers, and passes WebRTC signaling for the direct
  path.
- **Web** (`apps/web`, Vercel): the landing page, the device-login approval
  screen, and onboarding.
- **Protocol** (`packages/protocol`): the shared Zod message schema every part
  speaks.

## What Wrapper does

1. You open a terminal and the CLI hosts your real shell locally. Nothing is
   exposed.
2. `wrapper attach` mirrors that session from the same machine with no account
   and no network.
3. Pressing `Ctrl+\ s` shares the session and prints an access code. Your own
   devices can join directly; another user must supply that code.
4. Wrapper attempts a direct WebRTC data channel by default. The relay carries
   signaling and remains connected as the automatic fallback.

## Current status

The core platform is implemented and the native iPhone/iPad viewer foundation
has started in the separate mobile submodule:

- CLI host and attach flow (local and relay)
- Default-on direct WebRTC P2P fast path with relay fallback
- Device authorization login flow
- Web onboarding for first-run setup
- Backend session lifecycle and access control
- Relay ticket handshake and message routing
- Billing gate for relay sharing (Autumn Pro plan)
- CI for lint, format, typecheck, and tests, plus deploy automation
- Swift 6.2/SwiftUI mobile project, versioned protocol models, Keychain boundary,
  relay transport, SwiftTerm surface, and iOS CI
