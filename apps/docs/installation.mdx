## Requirements

- Bun 1.3.5 or newer
- macOS or Linux (on Windows, use WSL)
- A shell like zsh, bash, or fish

## Install the released CLI

Most users install the published binary. The install script downloads the right
archive for your platform, verifies its checksum, and unpacks it into
`~/.wrapper`:

```bash
curl -fsSL https://wrapper.sh/install | bash
```

On macOS you can also use the Homebrew tap:

```bash
brew install heycupola/tap/wrapper
```

## Run from source (development)

To hack on the CLI, install workspace dependencies from the repo root and run
the CLI with Bun. The commands below use `bun run apps/cli/index.ts` in place of
the installed `wrapper` binary.

```bash
bun install
```

## Install shell hooks

Use the CLI install command:

```bash
bun run apps/cli/index.ts install
```

This writes a managed block to your rc file and runs `wrapper shell-host` when a new shell opens.

## Start a host session

Open a new terminal or run manually:

```bash
bun run apps/cli/index.ts shell-host
```

## Attach from another terminal

```bash
bun run apps/cli/index.ts attach
```

If multiple sessions are live, you can choose from the picker or pass an id:

```bash
bun run apps/cli/index.ts attach --id <sessionId>
```

## Auth and relay attach

Login first:

```bash
bun run apps/cli/index.ts auth login
```

Then use relay attach. To join your own session from another device no code is
needed:

```bash
bun run apps/cli/index.ts attach --relay --id <sessionId>
```

To join someone else's shared session, run attach and enter the share code in the
hidden prompt:

```bash
bun run apps/cli/index.ts attach --relay --id <sessionId>
```

`--code` remains available for non-interactive automation, but interactive users
should avoid putting share codes in process arguments or shell history.
