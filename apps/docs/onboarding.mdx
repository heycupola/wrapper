## 1) Sign in

Use device auth from your terminal:

```bash
wrapper auth login
```

Open the displayed URL, sign in with GitHub/Google, and approve the code.

## 3) Start your host session

```bash
wrapper shell-host
```

This is your owner terminal.

The terminal title shows `host`, the short session id, and the active transport.
Wrapper prints the controls once the first prompt is idle. Press `Ctrl+\` at any
time to reveal the context-specific controls in the title without changing the
terminal screen.

## 4) Share and attach

In host terminal:

- `Ctrl+\` then `s` to share (prints a share code and the join command)
- `Ctrl+\` then `u` to unshare (revokes access immediately)
- `Ctrl+\` then `?` for status

From another device signed in as you, no code is needed:

```bash
wrapper attach --relay --id <sessionId>
```

To let someone else in (for example pair-prompting), give them the share code:

```bash
wrapper attach --relay --id <sessionId>
```

Wrapper asks a non-owner for the code in a hidden prompt. Every viewer who joins
can type into the same shell, so only share the code with people you want to
co-drive the session.
