# Web public assets

Drop landing-page media here. The horizontal landing hero expects:

- `wrapper-demo.mp4` — product demo video (autoplay, muted, looped). Keep it short
  (10-20s), H.264/MP4, ideally under ~8MB for fast load.
- `wrapper-demo-poster.png` — poster frame shown before the video loads.

Until these exist, the hero video area renders empty (poster fallback). Adding the
files with these exact names is all that's required; no code change needed.
