Wrapper is a terminal access platform with three core parts:

- CLI runtime that hosts your shell session
- Convex backend for auth and session lifecycle
- Relay service for remote WebSocket attach

## What Wrapper does

Wrapper starts from your shell and keeps your normal workflow intact.
When you choose to share a session, Wrapper exposes it through an authenticated relay path.

## Current status

The platform is complete up to mobile app development:

- CLI host and attach flow
- Device authorization flow
- Backend session lifecycle and access control
- Relay ticket handshake and message routing
- CI checks for lint, format, typecheck, and tests
